# ebook-reader

갤럭시(안드로이드)용 아주 가벼운 이북리더. 코믹뷰어와 같은 구조(즐겨찾기 · FTP · 내 폰)에
화면은 순수 흰색 바탕 + 검은 글자·1px 선만 쓴다.

## 설치 방법
코드가 `main`에 올라가면 GitHub가 자동으로 APK를 만듭니다.
저장소의 **Releases → 최신 빌드 → ebook-reader.apk** 를 폰에서 받아 설치하세요.
(코믹뷰어와 다른 앱이라 나란히 설치됩니다.)

## 읽을 수 있는 파일
- **TXT** — 인코딩 자동 판별 (UTF-8 / EUC-KR·CP949 / UTF-16)
- **EPUB** — 글자와 그림만 (꾸밈 CSS는 쓰지 않음)
- **PDF** — 안드로이드 기본 PDF 그리기 사용, 한 장씩
- **ZIP / CBZ 만화** — FTP에서 내려받지 않고 페이지별 스트리밍

FTP의 PDF·EPUB·TXT는 한 번 받아두고 다시 쓴다 (설정 → 저장공간에서 비우기).

## 화면
- 목록·뷰어 모두 흰 바탕(#FFFFFF), 글자·선은 검정(#000000). 회색 판·그림자 없음
- 목록은 글자 위주, ZIP·PDF·EPUB은 작은 표지 (설정에서 끌 수 있음)

## 만화 보기
- 설정에서 **두 장 · 가로 고정** 또는 **한 장 · 세로 고정** 선택
- 만화를 열 때만 화면을 강제로 돌린다 (목록·글자 책·PDF는 폰 방향 그대로)
- 두 장 보기는 왼쪽 → 오른쪽, **표지 따로** 켜면 첫 장만 혼자
